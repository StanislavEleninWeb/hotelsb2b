# Terraform — Infrastructure (Phase 1)

Reusable modules + per-environment wiring for the hotel booking platform on AWS,
following [`../Plan/02-architecture-mobile-security.md`](../Plan/02-architecture-mobile-security.md).

## Layout

```
terraform/
  bootstrap/   remote-state backend (S3 bucket + DynamoDB lock). Run ONCE per account.
  modules/
    network/   VPC, public+private subnets (2 AZs), IGW, NAT, flow logs
    security/  shared KMS key, generated DB/Redis secrets, 3rd-party key placeholders, CloudFront WAF
    compute/   ECS Fargate cluster, ALB, target groups, app/ALB security groups, task IAM roles
    database/  RDS PostgreSQL (private, encrypted; single-AZ staging / Multi-AZ prod)
    cache/     ElastiCache Redis (encrypted at rest + transit, AUTH token)
    storage/   S3 assets bucket (private, KMS, versioned, TLS-only) + access-log bucket
    cdn/       CloudFront (ALB + S3 origins, OAC), assets bucket policy, Route 53 records
  staging/     wires the modules — single-AZ, single NAT, small instances
  prod/        SAME modules — Multi-AZ RDS, HA Redis, per-AZ NAT, larger instances (STUB: not applied)
```

## Security posture

- `tfsec terraform` → **0 critical/high/medium/low**. The 32 inline
  `tfsec:ignore` directives are deliberate design decisions (public ALB and its
  443/80 ingress, app-tier egress, staging default TLS), each with a justification.
- No public S3 buckets (public access blocked everywhere); everything encrypted
  at rest; the only `0.0.0.0/0` ingress is 443/80 on the ALB security group.

## Usage

```bash
# 0. One-time: create the remote-state backend
cd terraform/bootstrap
terraform init
terraform apply -var state_bucket_name=hotel-terraform-state-<unique>

# 1. Point staging/backend.tf at that bucket, then:
cd ../staging
terraform init
terraform plan -var assets_bucket_name=hotel-staging-assets-<unique>

# Validate without AWS credentials / backend:
terraform init -backend=false && terraform validate
```

`prod/` is scaffolded but intentionally **not applied** — wire real domain, ACM
certs, and state bucket first.

## Notes

- CloudFront-scoped WAF lives in us-east-1 (the `aws.us_east_1` provider alias).
- DB and Redis credentials are generated by the `security` module and stored in
  Secrets Manager; the app reads them at runtime (never committed).
- `.terraform/`, `*.tfstate`, and `*.tfvars` are gitignored; `.terraform.lock.hcl`
  is committed.
